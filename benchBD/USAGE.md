# 财务管报压测 - 使用说明

## 项目概述
本项目用于对比阿里云Hologres和华为云DWS在财务管报场景下的性能表现，涵盖抵销、分销、科目上卷、维度拼接、YTD、同期数、行转列等典型财务分析场景。

## 快速开始

### 1. 环境初始化
```bash
cd /home/chaos/benchBD
./scripts/run_benchmark.sh setup
```

### 2. 配置数据库连接
编辑配置文件 `/home/chaos/benchBD/config.json`：
```json
{
  "databases": {
    "hologres": {
      "host": "your-hologres-host",
      "port": 80,
      "database": "your_database",
      "user": "your_username",
      "password": "your_password"
    },
    "dws": {
      "host": "your-dws-host",
      "port": 8000,
      "database": "your_database",
      "user": "your_username",
      "password": "your_password"
    }
  }
}
```

### 3. 运行压测
```bash
./scripts/run_benchmark.sh run
```

## 压测场景说明

### 1. 科目上卷查询
- **场景描述**: 递归查询会计科目层级，从叶子节点向上汇总
- **SQL特点**: 使用WITH RECURSIVE实现层级查询
- **性能指标**: 递归深度、查询时间、返回行数

### 2. 抵销处理
- **场景描述**: 集团内部交易抵销计算
- **SQL特点**: 多表关联、聚合计算、条件过滤
- **性能指标**: 关联效率、聚合性能

### 3. 分销业绩统计
- **场景描述**: 多维度分销渠道业绩分析
- **SQL特点**: 多表JOIN、GROUP BY、窗口函数
- **性能指标**: JOIN性能、聚合效率

### 4. YTD计算
- **场景描述**: 年初至今累计金额计算
- **SQL特点**: 窗口函数、分区排序
- **性能指标**: 窗口函数性能、排序效率

### 5. 同期数计算
- **场景描述**: 同比数据分析
- **SQL特点**: LAG函数、时间序列计算
- **性能指标**: 时间序列函数性能

### 6. 行转列
- **场景描述**: 数据透视操作
- **SQL特点**: CASE WHEN条件聚合
- **性能指标**: 条件聚合性能

### 7. 维度拼接
- **场景描述**: 多维度数据关联分析
- **SQL特点**: 多表LEFT JOIN、复杂GROUP BY
- **性能指标**: 多表关联性能

## 数据库差异说明

### Hologres特点
- 支持PostgreSQL语法
- 列式存储优化
- 实时分析能力强
- 索引支持有限

### DWS特点
- 支持PostgreSQL语法
- 分布式架构
- 支持复杂查询优化
- 索引支持丰富

- 最小/最大执行时间

### 2. 并发性能

## 结果分析

压测完成后，结果将保存在 `/home/chaos/benchBD/results/` 目录下：

1. **JSON格式详细结果**: 包含每次执行的详细信息
2. **控制台汇总报告**: 显示性能对比分析
3. **错误日志**: 记录执行过程中的错误信息

## 故障排除

### 常见问题

1. **数据库连接失败**
   - 检查网络连通性
   - 验证用户名密码
   - 确认数据库服务状态

2. **SQL执行错误**
   - 检查表结构是否创建
   - 验证数据是否导入
   - 查看SQL语法兼容性

3. **性能异常**
   - 检查数据量是否足够
   - 验证索引是否创建
   - 分析执行计划

### 调试模式
```bash
# 查看详细日志
python3 scripts/benchmark.py config.json --verbose

# 单次测试
python3 scripts/benchmark.py config.json --single-test
```

## 扩展使用

### 自定义压测场景
1. 在 `sql/` 目录下添加新的SQL文件
2. 修改 `benchmark.py` 中的场景识别逻辑
3. 重新运行压测

### 添加新的数据库
1. 在 `config.json` 中添加新的数据库配置
2. 创建对应的SQL文件
3. 修改压测脚本支持新数据库

## 注意事项

1. **数据安全**: 测试数据为模拟数据，不包含真实财务信息
2. **资源消耗**: 压测会消耗数据库资源，建议在测试环境运行
3. **网络稳定**: 确保网络连接稳定，避免压测中断
4. **权限要求**: 确保数据库用户有足够的权限执行测试SQL
