# 财务管报压测任务 - Hologres vs DWS

## 项目概述
本项目用于模拟财务管报场景下的数据库性能压测，对比阿里云Hologres和华为云DWS的性能表现。

## 压测场景
- **抵销处理**: 集团内部交易抵销
- **分销计算**: 分销渠道业绩统计
- **科目上卷**: 会计科目层级汇总
- **维度拼接**: 多维度数据关联
- **YTD计算**: 年初至今累计计算
- **同期数**: 同比数据计算
- **行转列**: 数据透视操作

## 项目结构
```
benchBD/
├── schemas/           # 表结构定义
│   ├── hologres/     # Hologres表结构
│   └── dws/          # DWS表结构
├── data/             # 数据生成脚本
├── sql/              # 压测SQL脚本
├── scripts/          # 压测执行脚本
└── results/          # 压测结果
```

## 使用方法
1. 根据目标数据库选择对应的表结构
2. 运行数据生成脚本创建测试数据
3. 执行压测脚本进行性能测试
4. 分析压测结果
